# 最小索引

已有规范优先；此结构是新建或获准调整索引时的基线，不授权静默迁移其他素材库。

```text
素材根目录/
  _索引/
    说明.txt
    素材.csv
  （沿用已有素材目录）
```

最小配置无需批次表、独立设备表或日志集合。CSV为UTF-8 BOM，一视频一行；XML以配套字段关联，多个配套文件遵循已有字段约定，不默默丢弃。

字段保持简洁：`路径,原名,来源,大小,SHA256,校验,状态,配套,关联,备注`。

- **路径、配套、关联**：相对于素材根目录，统一`/`，不含盘符、UNC或机器用户名。拒绝越出根目录的`..`。关联指向修复版对应原件；路径变更时同步修改引用。
- **来源**：历史溯源，不作当前定位。`素材:相对路径/原名.MP4`相对于素材根；`卡:DCIM/.../原名.MP4`相对于源卡根。前缀是来源类型，不是盘符。多卡或卡复用时，以已知卷/卡信息加本次导入标识区分来源，写入备注；卷名或硬件ID不能单独代表卡内这批内容，不编造硬件ID。来源记录历史位置，不随目标改名而变。
- **原名**：相机/源文件名。无需为保留它建立第二份媒体副本。哈希才用于判断字节内容一致，名称不能单独证明一致。
- **大小**：字节。**SHA256**仅填SHA-256值，未知留空；若库规定其他算法，遵循其既有字段，不能把别的算法值填进此列，调整字段先获许可；**校验**准确写明“源与目标哈希一致”或“仅改名及长度核对”。哈希一致不代表视频可正常解码。
- **状态**：正常、损坏原件、修复版或已移除等事实。已授权删除的行清空当前路径，保留原名、来源和简短原因；不要让历史哈希被误读为文件仍存在。
- **备注**：仅保留会影响使用或溯源的信息，如拍摄日期经用户纠正、码率实测、参考帧率推定、修复缺失音轨。不收集冗长执行过程。

说明.txt只需交代用途、上述字段/路径含义、更新时机和命名规范位置，内容应通用；不写本次旅行故事、软件运行日志、历史变更清单或设备知识库。已有说明如需修改，先取得许可。

更新前读取最新清单，只改受影响行，不覆盖无关素材；检查非空当前路径不重复、路径和配套存在、大小一致、关联有效、源盘符未泄漏。先校验临时CSV，发布前确认正式清单自读取以来未被其他操作修改；若已变化，重新读取合并，不能覆盖。再替换正式清单。仅清单覆盖的范围可作数量结论，未入索引不表示NAS没有该素材。

原名保留的行业依据：Pomfort Silverstack允许导入时重命名，同时保留原文件名供来源查询。这支持保留简短映射，但不能据此声称本流程等同所有制片方的完整DIT交付标准。
