# 充分性 8 维度评分细则

对应 Sufficiency Gate（G1/G2/G3, mode=sufficiency）。维度 1-6 每维度 1-5 分；维度 7-8 是 G3 专属的方向正确性质性检查（非评分），由举证责任锚定（principles.md 元原则 0）增强为「前提层 + 判据层」对抗。

**门槛**：适用评分维度加权平均 >= 3.5 通过；任一适用评分维度 <= 2 一票否决。维度 7-8 见各自的特殊裁决规则。

> **G1 候选集完备性**（仅选型类研究）是 G1 的独立质性检查，不占评分维度，见文末「候选集完备性检查」。

---

## 1. 覆盖度 (Coverage)

**定义**：信息源是否覆盖目标研究范围的各关键方面。

**适用**：G1 / G2 / G3

| 分数 | 标准 |
|------|------|
| 1 | 仅触及研究范围的单一方面 |
| 2 | 覆盖不足 50% 的目标范围 |
| 3 | 覆盖主要方面（>=70%），少数维度缺失 |
| 4 | 全面覆盖目标范围，无明显盲区 |
| 5 | 超出预期的覆盖面，发现新的有价值维度 |

---

## 2. 深度 (Depth)

**定义**：是否深入到可操作的洞察层级，而非停留在表面描述。

**适用**：G2 / G3

| 分数 | 标准 |
|------|------|
| 1 | 仅有概述级信息，无法支撑任何结论 |
| 2 | 停留在现象描述，缺少原因分析 |
| 3 | 主要方面有深入分析，部分维度浅层 |
| 4 | 各维度均达到可操作洞察层级 |
| 5 | 揭示底层机制和反直觉发现，洞察深度超出预期 |

---

## 3. 时效性 (Recency)

**定义**：信息是否足够新，能反映当前状态。

**适用**：G1 / G3

| 分数 | 标准 |
|------|------|
| 1 | 核心信息已过期（>2 年），严重失实风险 |
| 2 | 部分关键信息陈旧（>1 年），未标注时效 |
| 3 | 主要信息在 1 年内，个别历史数据已标注 |
| 4 | 核心信息在 6 个月内，历史数据均标注时效 |
| 5 | 信息高度时效（<3 个月），含最新动态和趋势 |

---

## 4. 可信度 (Credibility)

**定义**：信息源权威度的加权平均。

**适用**：G1 / G3

| 分数 | 标准 |
|------|------|
| 1 | 主要依赖不可靠来源（内容农场、未验证博客） |
| 2 | 部分引用权威源，但核心结论依赖低质量源 |
| 3 | 多数引用来自可信源（T1/T2），少数未验证 |
| 4 | 核心结论全部基于权威源（T1），辅助信息来自 T2 |
| 5 | 全部引用为权威源，含一手数据和官方发布 |

---

## 5. 双语平衡 (Bilingual Balance)

**定义**：中英文信息比例是否合理，避免单一语言视角偏见。

**适用**：G1 / G3

| 分数 | 标准 |
|------|------|
| 1 | 仅有单一语言信息源 |
| 2 | 次要语言信息源占比 < 20% |
| 3 | 中英文比例大致 40:60 - 60:40 |
| 4 | 中英文均有深度覆盖，已对比差异 |
| 5 | 双语信息充分交叉验证，地域偏见已识别并标注 |

---

## 6. 交叉验证率 (Cross-Validation)

**定义**：关键事实被多个独立来源确认的比例。

**适用**：G2 / G3

| 分数 | 标准 |
|------|------|
| 1 | 关键事实无交叉验证（< 20%） |
| 2 | 少数事实有交叉验证（20-40%） |
| 3 | 多数关键事实有 2 源确认（40-70%） |
| 4 | 核心事实均有 2+ 源确认（70-90%） |
| 5 | 全部关键事实经 3+ 独立源确认（>90%） |

---

## 7. 假设审计 (Assumption Audit)

**定义**：合并双环学习 + Key Assumptions Check（KAC）。既检查结论是否推翻原始问题假设（方向层），又检查支撑结论的全部前提是否成立（前提层）。借 Argyris-Schön 双环学习 + 情报界 SATs 关键假设检查。由元原则 0 增强，攻击「评审与生成共享同一套未验证前提」。

**适用**：G3（专属，非 1-5 评分）

**裁决规则**：

- **双环学习子项**：
  - 未发生双环（结论在原问题框架内成立）→ 继续 KAC 子项判定。
  - **发生双环（结论推翻了原始问题假设）→ 裁决 RECYCLE**，强制回退 G0 重校准问题定义，不继续往下走。这是 RECYCLE 区别于 FAIL 的核心触发点。
- **KAC 子项**：列出支撑核心结论的**全部前提**，逐条标注状态：
  - **Solid**：有证据支撑、已验证。
  - **Caveated**：在特定条件下成立，已标注条件。
  - **Unsupported**：未验证的假设。
  - **有 Unsupported 前提支撑核心结论 → 此项不通过（FAIL）**，要求补验该前提或显式降级结论的置信度后重审。

> 典型场景：前项目原假设「图扩展互补」，落地实测推翻——这是双环，本应触发 RECYCLE 回 G0。Track I「持久化索引是刚需」是未验证前提被当 Solid 用——这是 KAC 应拦截的 Unsupported。

## 8. 证伪审计 (Falsification Audit)

**定义**：合并反驳搜索 + 判据回链（cite 机械门）+ 证伪不可省（对称举证）。检查是否主动证伪、判据是否锚定根本目标、唯一证伪步骤是否被偷省。对抗 Einstellung Effect（只搜支持证据）+ status quo bias（现状默认正确）。由元原则 0 增强，攻击「判据层」。

**适用**：G3（专属，非 1-5 评分）

**裁决规则**（三子项，任一不通过即 FAIL）：

- **反驳搜索子项**：强制回答两问——「如果结论是错的，最可能因为什么？」+「是否已采集足以反驳的证据？」两问均有实质回答且采集了反驳向证据 → 通过；只搜支持证据 → FAIL。
- **判据回链子项（机械门）**：每个评判判据必须能 cite `research-goal.md` 的**具体小节标题或原句文本**（**不用行号**——Markdown 行号随编辑漂移会误杀）。cite 不上即判据无效（如用「是否有持久化索引」这类工具内在属性当判据，但它 cite 不到 primary_job/goal）。这是**机械裁决**，不要求 reviewer 主观重判前提——同模型 reviewer 主观审前提只会重演病灶（跳出回音壁）。
- **证伪不可省 + 对称举证子项**：结论为「维持现状 / 省成本 / 好收敛」时，唯一能证伪当前假设的步骤必须满足二选一——
  - 「已做」（实测/考古等证伪步骤已执行）；或
  - 「已显式记录豁免理由」（确证无法证伪 / 成本不对称，且写明理由）。
  - **两者皆无 → FAIL**。现状方案不享有「默认正确」信用；但回链得上 primary_job 的现状结论**不被额外惩罚**（防矫枉过正——惩罚的是偷省证伪的动作，不是现状这个方向）。

> 典型场景：Track I 第一版用未验证的「持久化是刚需」假设，省掉了唯一能证伪它的实测步骤——证伪审计应在此 FAIL。

## 候选集完备性检查（G1，仅选型类研究）

**定义**：选型类研究（N 个互斥方案择一）的候选集是否齐全、资料是否搜到饱和。对抗「只给 2 个选项不质疑遗漏」。借 Paul Nutt 多选项规则 + MECE + PRISMA 主题饱和。由元原则 0 在候选集层落点。

**适用**：G1（仅 `research-goal.md` 研究类型 = `selection`；非选型类 N/A，不强制）

**裁决规则**（质性，非评分）：

- **候选基数 < 3 → 强制补搜**（Nutt：单/双方案决策失败率远高于多方案）。补足 ≥3 个独立候选后方可进入 Decomposition。
- **饱和判定**：harvester 声明「搜完」须答「最近 2 轮检索有无新候选**类别**」。有 → 继续搜；无 → 允许停止，须在 fetch-report 标注 `saturation reached after N rounds`。
- 候选基数 < 3 未补搜、或未做饱和判定 → **G1 不通过（FAIL）**。
