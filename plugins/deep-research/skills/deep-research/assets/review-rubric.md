# 审阅 5 维度评分细则

对应 Validation Stage（mode=review）。每维度 1-5 分。

---

## 1. 准确性 (Accuracy)

**定义**：数据和事实是否正确，信息是否与原始来源一致。

| 分数 | 标准 |
|------|------|
| 1 | 存在重大事实错误，数据与来源不一致 |
| 2 | 多处事实未经验证，存在可疑数据 |
| 3 | 核心事实正确，少数细节未验证 |
| 4 | 数据经过交叉验证，事实准确 |
| 5 | 全部数据经多源交叉验证，精确度超出预期 |

**常见扣分项**：
- 引用数据与原文不一致（-2）
- 关键结论无交叉验证支撑（-1）
- 使用过时数据而未标注时效（-1）
- 翻译导致的语义失真（-1）

---

## 2. 完整性 (Completeness)

**定义**：是否覆盖研究范围的所有关键方面，无重大遗漏。

| 分数 | 标准 |
|------|------|
| 1 | 仅覆盖部分研究目标，重大遗漏 |
| 2 | 覆盖主要方面但缺少关键维度 |
| 3 | 覆盖所有主要方面，少数次要维度缺失 |
| 4 | 全面覆盖研究范围，无明显遗漏 |
| 5 | 超出研究范围的有价值延伸，覆盖度完整 |

**常见扣分项**：
- 研究目标中明确列出的方面未涉及（-2）
- 仅覆盖单一视角（如只有技术面缺市场面）（-1）
- 缺少竞争对手/替代方案的对比（-1）
- 中英文信息源覆盖严重失衡（-1）

---

## 3. 逻辑性 (Coherence)

**定义**：推理链是否严密，结论是否自洽，因果关系是否有据。

| 分数 | 标准 |
|------|------|
| 1 | 结论与论据矛盾，逻辑链断裂 |
| 2 | 推理跳跃明显，因果关系缺乏支撑 |
| 3 | 主要推理链成立，个别推论欠严密 |
| 4 | 推理链严密，结论自洽，论据充分 |
| 5 | 多层推理严密，反面论据充分考虑，结论稳健 |

**常见扣分项**：
- 结论与正文论据矛盾（-2）
- 相关性当因果性（correlation != causation）（-1）
- 忽略反面证据（-1）
- 不同章节之间结论互斥（-1）

---

## 4. 可操作性 (Actionability)

**定义**：建议是否具体可执行，读者能否据此采取行动。

| 分数 | 标准 |
|------|------|
| 1 | 仅有空泛建议，无法据此行动 |
| 2 | 方向正确但缺乏具体步骤 |
| 3 | 主要建议可执行，部分缺乏细节 |
| 4 | 建议具体，含时间线、资源需求、优先级 |
| 5 | 建议包含决策树、风险对冲方案和成功指标 |

**常见扣分项**：
- "建议关注 XX 领域"等空话（-2）
- 缺少优先级排序（-1）
- 未考虑实施约束（成本、时间、技术可行性）（-1）
- 建议相互矛盾或资源冲突（-1）

---

## 5. 可追溯性 (Traceability)

**定义**：结论是否能追溯到具体信息源，引用链是否完整。

| 分数 | 标准 |
|------|------|
| 1 | 大部分结论无来源，引用缺失 |
| 2 | 部分结论有引用，但链路不完整 |
| 3 | 核心结论可追溯，少数次要论点缺引用 |
| 4 | 全部结论可追溯到 pipeline 中的具体文件 |
| 5 | 引用精确到段落/数据点，读者可独立验证每个论断 |

**常见扣分项**：
- 关键数据无出处（-2）
- 引用链接失效或指向错误位置（-1）
- 间接引用未标注原始来源（-1）
- 参考文献列表不足 20 篇（-1）
